## Implementation steps

**1. `sql/10_schemas.sql`** — `CREATE SCHEMA IF NOT EXISTS` for RAW, CURATED, GOLD, APP as COCO_BUILDER (ownership matters).

**2. `sql/20_raw_synthetic.sql`** — ~5k customers via `GENERATOR`/`UNIFORM`/`RANDSTR`. Critical: assign each customer a hidden `TRUE_SEGMENT` (RETAIN / CROSS_SELL / UPSELL / SERVICE) first, then derive *both* their numeric behaviour *and* their `NOTE_TEXT` (from per-segment templates) from it. This is what makes evals scoreable. ~15k policies, ~8k claims, ~30k payments, ~25k interactions.

**3. `sql/30_curated.sql`** — cast/dedupe/conform; `INTERACTION_ENRICHED` adds `AI_SENTIMENT(NOTE_TEXT):categories[0]:sentiment::VARCHAR`. **Materialized as TABLE.** Run on `LIMIT 200` first.

**4. `sql/40_gold_c360.sql`** — dims/facts, then `CUSTOMER_FEATURES` (deterministic aggregates, no LLM) and `CUSTOMER_360`. Carry `TRUE_SEGMENT` through for eval only, marked `PRIVATE` in the semantic view.

**5. `sql/50_nba_ai.sql`** — the AI layer, as a **TABLE**:
- `AI_CLASSIFY(PROFILE_TEXT, [{label,description} x4], {'task_description':...}):labels[0]::VARCHAR AS NBA_ACTION`
- `AI_COMPLETE('llama3.1-8b', prompt, model_parameters => {'temperature':0,'max_tokens':300}, response_format => TYPE OBJECT(rationale VARCHAR, talking_points ARRAY(VARCHAR), confidence FLOAT))`
- Gate: build `CUSTOMER_NBA_SAMPLE` at `LIMIT 50`, eyeball quality, measure credits via `coco_admin` against `CORTEX_FUNCTIONS_USAGE_HISTORY`, extrapolate, *then* run all 5k. Escalate to `llama3.3-70b` only if 8b quality fails eval.
- Retry pass: `WHERE result IS NULL` to catch transient rate-limit nulls.

**6. `sql/60_semantic_view.sql`** — `CREATE SEMANTIC VIEW GOLD.C360_SV` over DIM/FACT/FEATURES/NBA. Clause order is **enforced**: TABLES → RELATIONSHIPS → FACTS → DIMENSIONS → METRICS → COMMENT → `AI_VERIFIED_QUERIES`. Synonyms on customer-facing dims; 5–6 verified queries; correct `PRIMARY KEY`s (wrong PKs silently inflate metrics).

**7. `sql/70_agent.sql`** — `CREATE AGENT APP.NBA_ADVISOR ... FROM SPECIFICATION $$...$$` with `cortex_analyst_text_to_sql` → `C360_NBA.GOLD.C360_SV`, plus `data_to_chart`. Grant `USAGE ON AGENT` to the end-user's **default** role.

**8. `app/streamlit_app.py` + `app/snowflake.yml`** — `definition_version: 2`, `runtime_name: SYSTEM$ST_CONTAINER_RUNTIME_PY3_11`, `compute_pool: SYSTEM_COMPUTE_POOL_CPU`, `query_warehouse: COCO_WH`, no `pyproject.toml`. `st.connection("snowflake")`, `@st.cache_data(ttl=600)` on every query. Customer search → 360 profile → ranked NBAs with rationale/talking points. Deploy: `cd app && snow streamlit deploy --connection coco --replace`.

**9. `evals/nba_evals.yaml` + `evals/run_evals.sql`** — score `NBA_ACTION` vs `TRUE_SEGMENT`: overall accuracy, per-class confusion matrix, null rate, plus ~10 NL questions for the semantic view with expected-answer assertions.

**10. `sql/99_teardown.sql`** — drop schemas/warehouse/monitor to stop the trial bleeding.

**11. `docs/README.md`** — run order, cost notes, gotchas.
